# Duct ANC 毕业设计 · 讨论中心

题目：管道（通风口）主动降噪。噪声先经过参考麦克风，控制器算出反相声，由扬声器注入，误差麦克风检测剩余噪声并修正滤波器，使出口处的噪声降下来。

## 目录

| 路径 | 内容 |
| --- | --- |
| `00_原始资料/总体设计架构.md` | 原课程设计总体架构（基于 STM32F407 + FxNLMS），本次评估的对象 |
| `01_设计评估.md` | 对总体架构的评估：成立的部分、风险、建议的改进与毕设加深方向 |
| `02_讨论记录.md` | 待决问题、决策记录、按日期追加的讨论 |
| `03_参考资料.md` | 书籍、经典论文、器件手册清单 |
| `firmware/hwtest/` | 基础硬件测试固件（StdPeriph + FreeRTOS）：蓝牙通信、扬声器控制、麦克风测量，使用说明见其 README |
| `host/` | 上位机 Python：`hwtest.py`（蓝牙命令、采集、自检）、`analysis.py`（频谱/相干分析） |
| `资料/论文/` | 放论文 PDF |
| `资料/数据手册/` | 开发板原理图（`开发板原理图_stm32f407v.pdf`），以及 STM32F407、MAX4466、PAM8403、扬声器等手册 |
| `资料/图片/` | 框图、实物照片、频谱截图 |
| `实验记录/` | 每次测量的 WAV、频谱、相干函数和结论 |

## 使用约定

- 新的讨论追加到 `02_讨论记录.md`，标日期；定下来的事写进该文件的「决策记录」表。
- 原始资料只读，修改意见写进评估或讨论文件。
- 原文档里链接的 `系统结构.md`、`算法推导.md`、`时延预算.md` 等以及 `sim/`、`firmware/`、`cad/` 都在原仓库（`COSMOS-LYX/duct-anc-stm32`）里，当前文件夹里还没有。需要时再拉进来。
