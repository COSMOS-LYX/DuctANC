## 这次烧进去的是什么

ST-LINK 37FF71064E57343665F41043，3.29 V，下载校验通过并软件复位。芯片里现在有 getline 的修改：命令以 `\r\n` 结尾时，`\n` 不再留在接收缓冲里。上位机的 `XCHK` 已改回走普通的 `\r\n`。这次对账就是用 `\r\n` 做的，400 点最大误差仍是 0。`rxovf` 是 0。

静音时序和上一轮一致：CPU 34%–36%，写槽 12 µs，三次一样，`slip`/`late`/`ovr`/`udr` 都是 0，DAC 全是 2048。基线 25.5 mV，误差麦 23–30 mV，200 Hz 约 3 mV。三次 CAP 回传期间保护没有锁。上一轮那次 493 mV 没有复现；至少这一轮，串口送数本身没有把误差麦推过门槛。

`‖W‖` 从 0.14 增到 0.78。`CLAMP 0` 把输出按在中点，更新仍在跑，误差麦不是 0，所以 W 会慢慢长。这是开环，不是喇叭在响。`clamp_n` 一直在涨，是因为限幅为 0 时只要 y 不是整数 0 就算碰上。测完已经 `ANC OFF`，W 是 0。限幅已设回 ±40，状态行读到 `clamp=40.0`、`on=0`、`prot=0`。
